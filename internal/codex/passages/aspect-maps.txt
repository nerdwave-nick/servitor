An object keyed by aspect, with "*" serving every aspect it does not name

Some words of a rite must change with the aspect it is invoked into: the
omen each subject bears, the word an inscription decrees. Such a value is an
aspect map: an object whose every key names a declared aspect and holds that
aspect's value, the key "*" serving every aspect not named. An aspect named
in the map is always answered by its own value; "*" speaks only for the
rest. In pattern Mark II an aspect map is always an object, even when one
value serves every aspect: {"*": "…"}. There is no form of "a plain value
or a map".

These values are aspect maps: the "omens" of every subject, and the
"decrees" of an inscription of a rite of aspects. The "enact" words and
"trials" of a machine-spirit are maps of the same shape, keyed by omen in
place of aspect. All else holds one value for every aspect — the vessel,
the bound name, ward, glyphs, consecrate, seal, zeal, tongue and patience,
for omens and markers must know one fixed place, and the words, scroll,
offerings and reversion of an observance, which differ by aspect only as
several observances guarded by "to".

A key that names no declared aspect is heresy, for a misspelt aspect would
otherwise be served in silence by nothing. An aspect map that gives an
aspect no value and holds no "*" is heresy too: were the rite invoked into
that aspect, the servitor would not know what to do. Only decrees are
spared this, for an inscription may leave an aspect without decree.

An aspect map may still speak placeholders in each of its values: within
an omen, {{aspect}} names the aspect whose omen it is, so a single "*"
often serves where many keys would be written.

An edict bears no aspect to key a map by, so every value of an edict is
written once and plainly: an aspect map in an edict is heresy wherever it
stands, even one keyed by "*" alone, and its decree is one plain word.

In the elder pattern "Mark I" any value of a step — its scripture, anchor,
words, scroll, offerings or reversion — might be one plain value or an
aspect map. Conversion writes every such map as an object, makes the
scripture or anchor of a step the omens of its subject, and splits words
that differ by aspect into observances guarded by "to" (see conversion).

Kindred passages: aspects, omens, placeholders, decrees, enact, edict,
conversion

Exempla:
  // a named aspect, and "*" for every other
  "omens": {"on": "do-not-disturb", "*": "default"}

  // one omen for every aspect, each its own through {{aspect}}
  "omens": {"*": "~/.config/nfluff/themes/{{aspect}}"}

  "decrees": {"on": "auto-hide", "off": "always-visible"}
